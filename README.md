# 우리집 가계부

부부가 같이 쓰는 가계부 웹앱. 데이터는 JSON 파일 하나로 관리하고, 그 파일을 iCloud나 구글드라이브 공유 폴더에 둔다.

## 지금 바로 열어보기 (맥)

```bash
cd '/Volumes/Workspace/자산관리/가계부앱' && python3 tools/serve.py
```

브라우저에서 http://localhost:8765 를 연다. (크롬을 권장 — 공유 폴더 파일에 바로 저장하는 기능이 크롬에서만 된다.)

## 화면

| 탭 | 하는 일 |
|---|---|
| 대시보드 | 이번 달 소비, 고정비/변동비, 월별 추이 그래프, 카테고리별 소비(전월 대비) |
| 투자 | 실제 투입 원금 대비 성과. 원금 입출금과 평가금액을 직접 고칠 수 있음 |
| 대출 | 잔액·이자·원금 분해, 잔액이 줄어드는 곡선, 미리 갚을 때 아끼는 이자 계산. 대출 여러 개 등록 가능 |
| 리포트 | 달마다 자동 분석 — 평균 대비 변화, 큰 지출, 매달 반복되는 결제, 순자산. 요약문 복사 |
| 거래내역 | 검색·필터, 카테고리·종류 바꾸기, 집계 제외, 삭제 |
| 입력 | 수기 입력 + 카드사·은행 파일 업로드 (중복·금액 불일치·누락을 대조해서 알려줌) |
| 설정 | 피드백 남기기, 데이터 파일 연결·내보내기, 새로 시작하기, 사용자·계좌·카테고리 관리 |

위쪽 **통합 / 진호경 / 박혜민** 버튼으로 사용자를 나눠 보거나 합쳐 볼 수 있다.

## 피드백

설정 탭 맨 위에서 쓰면서 느낀 점을 남길 수 있다. **보기 모드에서도 쓸 수 있어서** 누구나 바로 적을 수 있다.
누가·무엇(안 되는 것/이렇게 됐으면/궁금한 것)·내용이 데이터 파일에 같이 저장된다.
앱을 고칠 때 **전체 복사**로 목록을 넘기거나, 데이터 파일을 보내면 그 안에 다 들어 있다. 처리한 것은 '반영됨'으로 표시해두면 된다.

## 보기 모드와 편집 모드

열면 항상 **보기 모드**다. 이 상태에서는 카테고리·금액·평가금액을 건드릴 수 없어서 폰에서 잘못 눌러도 안전하다.
고치려면 위쪽 **편집** 버튼을 누른다. 새 거래를 추가하거나 파일을 올리는 것은 보기 모드에서도 된다(기존 내역을 바꾸지 않으므로).

## 서버와 비용

서버가 필요 없다. 앱은 HTML·CSS·JS 파일 몇 개일 뿐이고, 가계 데이터는 내 클라우드 폴더에 있는 JSON 파일 하나다.

- **호스팅 비용:** 0원. GitHub Pages·Vercel 무료 요금제면 충분하다. 올라가는 것은 앱 코드뿐이고 **가계 데이터는 절대 올라가지 않는다.**
- **왜 그래도 호스팅을 하나:** 아이폰 사파리는 파일 앱에 있는 HTML을 직접 열지 못한다. 폰에서 쓰려면 주소가 있어야 한다.
- **맥만 쓴다면 호스팅도 필요 없다:** `가계부_단독본.html` 한 파일을 iCloud 폴더에 두고 더블클릭하면 된다.

## 오프라인

- **호스팅한 앱:** 한 번 열어두면 앱 파일이 캐시에 저장되어(서비스 워커) 비행기 안에서도 열린다.
- **단독본 파일:** 인터넷이 아예 필요 없다. 그래프 라이브러리까지 파일 안에 들어 있다.
- 어느 쪽이든 수정한 내용은 브라우저에 먼저 저장되고, **저장**을 누를 때 클라우드 폴더 파일에 반영된다.

## 데이터 파일 다루기

- **맥 크롬:** 설정 → `공유 폴더 파일 연결`로 `가계부_데이터.json`을 한 번 지정하면, 이후 고칠 때마다 **2.5초 뒤 자동 저장**된다. iCloud가 그 파일을 알아서 동기화한다.
- **아이폰 사파리:** 파일 직접 연결이 안 된다. **저장**을 누르면 파일이 내려받아지고, 파일 앱에서 공유 폴더에 덮어쓰면 된다. 불러올 때는 설정 → `파일 가져오기`.
- 브라우저에도 자동으로 사본이 남으므로, 저장을 깜빡해도 다음에 열면 이어서 작업할 수 있다.
- **두 사람이 동시에 고치면 나중에 저장한 쪽이 이긴다.** 같은 시간에 같이 입력하지 않는 게 안전하다.

## 매달 하는 일

1. 카드사·은행에서 이용내역 파일을 받는다.
2. **파일 업로드** 탭에 넣는다. 이미 있는 건 건너뛰고 새 거래만 들어간다.
3. 중복·금액 불일치·누락으로 표시된 것만 확인한다.
4. 현금으로 쓴 것은 **입력** 탭에서 추가한다.
5. **저장**을 누른다.

## 아이폰에서 앱처럼 쓰기

1. 앱을 인터넷 주소에 올린다 (아래 '올리기' 참고).
2. 아이폰 **사파리**로 그 주소를 연다. (크롬 말고 사파리여야 홈 화면 추가가 된다)
3. 아래 **공유** 버튼(↑) → **홈 화면에 추가**.
4. 홈 화면 아이콘으로 열면 주소창 없이 전체화면이고, 인터넷이 없어도 열린다.
5. 처음 열면 '처음 오셨네요' 화면이 나온다. **데이터 파일 불러오기** → iCloud 공유 폴더의 `가계부_데이터.json`을 고른다.
6. 입력한 뒤 **저장**을 누르면 공유 창이 열린다. **파일에 저장** → 공유 폴더를 골라 덮어쓴다.

## 올리기 (GitHub Pages)

`자산관리/배포용_가계부앱/` 폴더가 올릴 파일만 모아둔 것이다. **가계 데이터는 들어 있지 않다.**

1. github.com → **New repository** → 이름은 영문으로 (예: `budget`) → Public → Create
2. **uploading an existing file** 클릭
3. Finder에서 `배포용_가계부앱` 폴더를 열고 **그 안의 파일·폴더 전체**를 드래그
   (폴더 자체를 올리면 주소에 한글 폴더명이 들어가니, 반드시 안의 내용물을 올린다)
   - index.html, app.css, sw.js, manifest.webmanifest, README.md, js/, vendor/, icons/
4. **Commit changes**
5. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save
6. 1~2분 뒤 `https://<아이디>.github.io/budget/` 로 접속

앱을 고쳐서 다시 올릴 때도 같은 자리에 파일을 덮어쓰면 된다. 폰에서 옛날 화면이 보이면 새로고침하면 새 버전을 받는다.

넷리파이(app.netlify.com/drop)에 폴더를 끌어다 놓는 방법도 있다. 둘 다 무료이고, 올라가는 것은 앱 코드뿐이라 주소를 아는 사람이 열어도 빈 화면만 보인다.

## 데이터 형식

`가계부_데이터.json` 한 파일에 모두 들어 있다.

- `transactions`: 거래. **지출은 음수(−), 수입은 양수(+)**
  - `type`: `expense`(소비) / `income`(수입) / `transfer`(계좌이체) / `investment`(투자) / `card_payment`(카드대금)
  - 소비 통계는 `expense`만 센다. 그래서 카드대금 자동이체나 계좌 간 이체가 이중으로 잡히지 않는다.
- `categories`: 고정비 5 / 변동비 16 / 일회성 2. `keywords`로 자동분류
- `investment.flows`: 투자 원금 입출금. `include: false`면 계좌 안에서 옮긴 돈이라 원금에서 뺀다
- `investment.holdings`: 보유 자산과 평가금액

## 단독본 파일 만들기

```bash
python3 tools/build_single.py
```

`가계부_단독본.html`(1.3MB) 하나가 만들어진다. 앱 코드·그래프 라이브러리·현재 데이터가 모두 들어 있어 서버도 인터넷도 필요 없다.
단, 단독본은 만들어진 시점의 데이터를 품고 있으므로, 최신 데이터는 앱에서 `파일 가져오기`로 불러온다.

## 새로 시작하기

카드·은행 파일을 처음부터 다시 올리고 싶으면 설정 → **새로 시작하기**를 쓴다. 지우기 전에 **파일 내보내기**로 백업해둘 것.

- **거래내역만 지우기** — 계좌·카테고리·대출·투자 설정은 그대로, 거래만 비운다
- **전부 지우기** — 빈 가계부로 되돌린다
- **이 기기의 사본 지우기** — 공유 폴더 파일은 그대로 두고 이 브라우저에 남은 데이터만 지운다

참고: 카드사 사이트는 보통 최근 3개월치만 받을 수 있다. 지금 들어 있는 3~9월 자료는 다시 구하기 어려울 수 있으니, 지우기보다 **그대로 두고 새 파일을 얹는 것**을 권한다. 중복은 자동으로 걸러진다.
